活動統計新增「類型篩選」：

- 新增下拉選單「全部類型」
- 類型會自動由現有活動紀錄產生

  家長聯絡（12）
  補課（5）
  學生支援（8）

  全學年／上學期／下學期／本月
  搜尋關鍵字
- 匯出 CSV 及列印／PDF 會跟目前篩選結果
- 新增／刪除活動後，類型選單會自動更新
