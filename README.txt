香港教師教學日誌 v2.0.3 — 班別可自訂輸入

新增：
1. 待辦工作範圍選「班別」後：
   - 顯示正式班別清單
   - 最後新增「其他班別／自行輸入」

2. 選「其他班別／自行輸入」：
   - 顯示文字欄
   - 可輸入例如：
     4E
     5B補課組
     P.4跨班小組

3. 資料儲存：
   - scopeType = class
   - scopeName = 自行輸入班別
   - scopeId = 空白
   - 不會自動加入 classProfiles
   - 不會污染正式班別／學生中心

4. 修改待辦：
   - 同樣可以由正式班別轉成其他班別
   - 亦可以由其他班別轉回正式班別

5. Inbox：
   - 班別篩選會包括自行輸入的外部班別
   - 例如 4E 即使不是正式任教班別，都可以篩選

6. 搜尋：
   - 原有 scopeName 搜尋保持有效
