香港教師教學日誌 v2.8.5 — 追收篩選總覽＋班級中心封存狀態
更新日期：2026-10-08

一、修正「待追收」篩選
======================
「待追收」現在定義為：
- 未封存（不是不再追收）
- 仍然有欠交學生
- 不論是否已過追收死線，都會列入待追收

「已過期」仍可另外篩選。
刪除「未能追收」作為頂層篩選；未能追收仍保留為個別學生資料。

二、每個篩選都有簡短總覽
========================
篩選後直接列出每個追收項目：
- 班別＋項目名稱
- 繳交／追收日期
- 已交 X
- 欠交 Y
- 未處理 Z
- 如已封存，顯示「不再追收」

按總覽卡即可打開該項目的詳細追收狀態。

三、班級中心加入「不再追收」
============================
- submissionProgress 新增 archived 狀態。
- 班級中心「追收」Tab 會顯示：
  已交｜欠交｜未處理｜不再追收
- 班級中心總覽的「未完成追收」不再將已封存項目當成進行中。
- 會額外顯示「歷史：不再追收 X 項」。

四、保留
========
- 整項「不再追收」及 Firestore 同步
- 重新追收
- 今日／班別／狀態／類別篩選
- 個別學生「未能追收」
- PWA／iPad／離線同步等既有功能
