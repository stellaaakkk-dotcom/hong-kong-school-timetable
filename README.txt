香港教師教學日誌 v2.0.0 — 教師工作台核心

今次不是加幾個小功能，而是建立新架構。

A. 班別／學生資料核心
- 更多 → 記錄 → 👥 班別／學生
- 可建立班別及學生名單（每行一位）
- 自動由現有功課／追收辨認已有班別
- 班別資料儲存在：
  localStorage: hk-school-class-core-v2
  Firestore: users/{uid}/classProfiles/{classId}
- 呢份資料會成為之後：
  座位表、積分、學生紀錄、追收的共用學生核心

B. 課堂工作流
- 更多 → 工作台 → 🧭 課堂流程
- 揀日期／節數
- 直接讀主日誌真正課堂資料
- 集中顯示：
  上次同班進度
  今堂進度
  今堂功課
  追收狀態
- 可以：
  前往日誌
  查看追收／前往功課
  為該堂快速建立待辦

C. 統一 Inbox
- 更多 → 工作台 → 📥 統一 Inbox
- 合併：
  未完成待辦
  deadline
  功課追收
- 按班別／類型篩選
- 排序：逾期 → 今日 → 之後
- 可直接：
  開啟待辦
  開啟追收
  完成待辦

D. 教師工作台 v2 首頁
- 更多 → 工作台 → 🧰 教師工作台 v2
- 顯示 KPI：
  班別數
  學生數
  追收中
  逾期
- 四個核心入口：
  班別／學生中心
  課堂工作流
  統一 Inbox
  班別總覽

架構原則：
- 不新增 React tab
- 不替換 .workspace
- 全部用 body-level modal
- 保留 v1.9.6 所有穩定功能

之後 v2.1：
- 座位表直接讀 classProfiles 學生名單

之後 v2.2：
- 積分／課堂表現使用同一 student/class core

Service Worker cache：v200
