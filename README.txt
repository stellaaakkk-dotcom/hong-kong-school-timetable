香港教師教學日誌 v2.4.5 — Tutorial 流程關閉／入口／座位功能修正

新增／修正：
1. 功課管理入口
- 新增一步：「More → 工作台 → 功課管理」。
- 自動打開工作台並高光「📚 功課管理」。

2. 功課管理自動關閉
- 離開功課管理步驟（下一步／上一步）時，自動關閉 #pe-homework-modal。
- 由入口步驟離開時亦自動關閉工作台 modal。

3. 學生 Tab / Profile 自動關閉
- 離開「學生 Tab 同 Profile＋」步驟時，自動關閉班級中心。
- 避免遮住下一步座位／積分。

4. 座位表／積分功能介紹
- 座位／積分後新增一步介紹主要分頁：
  今日、學生、座位、積分、紀錄、更多。
- 高光 iframe 底部功能分頁區。
- 離開座位功能介紹後自動關閉座位／積分，方便下一步進入雲端帳戶。

核心同步／Profile／追收資料結構不變。
