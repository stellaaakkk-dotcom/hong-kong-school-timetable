香港教師教學日誌 v2.8.3 — 整項追收封存＋篩選
更新日期：2026-10-08

主要更新
========
1. 「不再追收」改為整個追收項目封存，不再逐個學生處理。
2. 封存後不再出現在「今日追收」及「進行中」。
3. 追收歷史新增獨立「不再追收」分類。
4. 封存保留完整欠交學生、原因、備註及日期。
5. 可由歷史按「重新追收」恢復。
6. 「未能追收」繼續保留為個別學生狀態。
7. 新增追收篩選：
   - 日期：全部／今日要追收
   - 班別
   - 狀態：待追收／未能追收／未處理／已交齊／已過期／不再追收
   - 類別

舊 v2.8.2 個別停止追收資料仍保留可讀，但新操作不再建立該類資料。

部署：7 個執行檔 + README.txt。
