香港教師教學日誌 v1.8.2

本版主要修正兩點：

1. 「更多」介面美化
- 保留「今日／記錄／工具」三組。
- 每組改成獨立卡片。
- 標題、按鈕高度、間距、圓角統一。

之前錯誤原因：
- v1.8.1 用「由開學日起計平日」自行推算 Day 1–6。
- 主日誌其實使用學校實際日期→Day 1–6／A-B 對照表，會跳過假期及非循環日。

v1.8.2：
- index.html 直接把主日誌正在使用的真實循環表暴露給功課紀錄模組。
- 功課紀錄用「日期＋lessonNotes 內的實際節數」。
- 再用同一日誌的實際 Day 1–6 + A/B 色週過濾 daySubjects。
- 第9節亦按實際星期及單／雙週規則處理。
- 因此班別／科目會跟返原日誌該一日該一節。
- 只有主日誌該節本身無法辨認班別時，先 fallback 到追收紀錄／文字。
