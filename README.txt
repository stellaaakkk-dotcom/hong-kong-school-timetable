香港教師教學日誌 v2.8.2 — 「不再追收」＋追收歷史
更新日期：2026-10-08

新增
====
欠交學生現在有三個處理：
1. 已補交
2. 未能追收
3. 不再追收

「不再追收」
============
- 學生仍然保留為欠交，不會變成已交。
- 從目前待追收名單及「今日追收」移走。
- 收入該功課／回條內的「追收歷史」。
- 歷史保留班號、欠交原因、備註、結束追收日期。
- 可按「重新追收」恢復到目前待追收名單。
- studentHistory 會保留 stop-followup / reopen-followup 紀錄。

統計
====
「欠交」仍計入不再追收學生，保持事實正確。
目前追收則只計仍需追收的學生。
