香港教師教學日誌 v2.8.7 — V2.6 雲端鏡像 Phase 1
更新日期：2026-10-09

目標
====
開始將仍然 localStorage-backed 嘅資料安全雲端化：
- 身份層 Identity V1
- 座位
- 積分
- 學生 Profile（私人備註、家校聯絡、課堂事件等，隨班級座位資料一併鏡像）

本機資料仍然保留，雲端係額外鏡像／跨裝置來源。

雲端位置
========
users/{uid}/cloudMirror/identity-v1
users/{uid}/seatProfileClasses/class_<hash>

安全設計
========
1. Identity 採用非破壞式合併：
   雲端歷史學生／Enrollment 唔會因新裝置資料較少而被刪走。

2. Seat/Profile 防止新裝置誤覆寫：
   如果雲端已有目前班別資料，而呢部裝置從未認領／載入過，
   自動同步會暫停，狀態顯示「有雲端資料待載入」。

3. 手動備份可以強制將本機版本寫到雲端，但會先確認。

4. 從雲端載入 Seat/Profile 只影響目前班別；
   載入後再同主系統 Class Core 對齊 studentId／姓名／rosterVersion。

入口
====
班級中心 → 健康檢查 → ☁ 雲端鏡像 Phase 1

按鈕
====
- 立即備份到雲端
- 從雲端載入身份層
- 從雲端載入目前班別座位／Profile

自動同步
========
- 身份層變動後延遲鏡像到雲端。
- 座位／積分／Profile 變動後延遲鏡像目前班別。
- 如新裝置偵測到已有雲端資料但未載入，唔會自動覆寫。

注意
====
第一次跨裝置測試建議：
A 裝置先「立即備份到雲端」；
B 裝置登入同一帳戶、先開一次座位／積分，再到健康檢查選「從雲端載入」。

其他功能全部沿用 v2.8.6 / v2.8.5 穩定基準。

部署：7 個執行檔 + README.txt。
