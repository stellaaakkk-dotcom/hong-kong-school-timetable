香港教師教學日誌 v1.9.1

修正 3 個功課紀錄問題：

1. 期間篩選
- 修正「本週／本月／本學期／自訂」按完後 render 又回到全部的問題。
- period 狀態會保留在 modal dataset。
- 每次 render 都會重新同步 active bubble。
- 自訂日期輸入亦會保留。

2. 追收狀態
- 不再只靠 sourceKey 完整字串硬比對。
- 比對次序：
  ① sourceKey 日期＋功課內容
  ② 同日期＋同班別＋功課／標題／來源文字相似
  ③ sourceKey 內含日期＋相似內容 fallback
- 功課紀錄可顯示：
  未追收／追收中／已交齊

3. 重複功課提示
- 一個功課 box 會先按換行拆成多個項目。
- 每一行獨立比較過去 21 日同一班功課。
- 例如：
  詞語 1-10
  作業 P.4
  默書改正
  只要其中任何一行之前出現過，就會獨立提示。
- 可同時提示多個重複項目。

其他 v1.9.0 功能保留。
