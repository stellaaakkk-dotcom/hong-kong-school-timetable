香港教師教學日誌 v2.2.3 — 日誌多份功課分行追收

新規則：
- 日誌「功課」欄每一個非空白換行 = 一份獨立功課
- 按「＋追收」後會先顯示偵測到的功課清單
- 每份功課可獨立勾選
- 未加入項目預設勾選
- 已加入項目會顯示「已加入追收」並停用，防止重複

新增後：
- 每一行建立獨立追收紀錄
- 每份功課各自有欠交名單／狀態
- 共用班別、派發日期、繳交日期、追收死線
- 繳交日期仍使用 v2.2.2「下一個上學日」規則

追收按鈕狀態：
- 1份：＋追收
- 多份未加入：＋追收（3份）
- 部分已加入：＋追收 1/3
- 全部已加入：已加入 ✓

空白行自動忽略。
