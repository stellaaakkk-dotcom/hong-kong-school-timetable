香港教師教學日誌 v2.4.24 — 月曆教學高光修正

月曆教學：
1. 月曆主畫面
- 不再高光整張 paper / preview-wrap。
- 只高光 calendar-layout（實際月曆格＋右側備忘欄）。
- 避免將下面空白區一併框住。

2. 日期快捷新增
- 不再高光整個日期格。
- 直接高光真正可點擊的日期數字 <b>（例如 11）。
- 教學文字改為「撳日期數字開快捷新增」。

3. 輸入後查看
- 返回月曆後高光完整日期格，方便看到記事 / tag。

4. 高光定位
- spotlightRect 改成按 viewport 左／上／右／下實際可見交集裁切。
- 月曆專用高光會在 scroll 後重新量度 3 次，配合手機平滑捲動。
- 月曆提示文字固定合理橫向寬度，不再因細日期格而變成直排長條。

其他頁面、今日課表、總課表、日誌及其他教學步驟不變。
