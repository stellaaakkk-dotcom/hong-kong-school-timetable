香港教師教學日誌 v2.8.6 — 資料健康檢查
更新日期：2026-10-08

更新目的
========
將原本已有但較隱藏的 V2.5 跨模組一致性診斷，
正式整理成日常可用的「資料健康檢查」。

新入口
======
1. 班級中心 → 健康檢查
2. 工作台 → 資料健康檢查

簡短總覽
========
會顯示：
- 身份／Enrollment 是否正常
- Pending 孤兒 Student ID 數量
- 追收班別未配對數量
- 座位 adapter 是否已連接
- 待同步寫入數量

完整健康檢查
============
按「開啟完整健康檢查」會打開原有身份與跨學年資料 V1，
當中包括：
- classId / studentId 核心診斷
- duplicate ID
- orphan student pending
- legacy pending / legacy submission
- 暫時班號 Enrollment
- Pending 跨模組連結
- 追收班別配對
- 座位班別／Student ID／缺漏學生
- queued writes

安全原則
========
今版只診斷，不會自動修改 ID、班別、學生、追收或座位資料。
座位診斷要先開過一次「座位／積分」，adapter 先有完整資料。

其他功能
========
全部沿用 v2.8.5 穩定基準：
- 追收篩選與簡短總覽
- 不再追收封存
- 班級中心不再追收狀態
- 活動快速新增
- 版本提示
- PWA／iPad／離線同步

部署：7 個執行檔 + README.txt。
