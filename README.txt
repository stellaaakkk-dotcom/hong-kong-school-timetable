新增 1：活動統計快速新增
========================
活動統計頂部新增「＋ 快速新增活動」。
可一次輸入：活動類別、活動名稱、備註，然後加入多個日期。
日期可以：
- 用日期欄逐個加入成 chips
- 或一次貼上多個 YYYY-MM-DD（每行／逗號／空格分隔均可）

活動統計每一筆紀錄亦新增「＋再記錄」：
- 自動帶入原本類別／名稱／備註
- 只需加入新日期
- 適合相同活動在不同日子重複發生

新增 2：版本顯示／更新提示
==========================
畫面右上附近會顯示目前版本，例如 v2.8.0。
按版本可手動檢查 version.json。
偵測到新版時會顯示：
「偵測到新版」＋「立即重新載入」
並顯示目前版本 → 新版本。

更新行為
========
不再由 index.html 靜默直接 location.replace。
改為先提示使用者，再由使用者按「立即重新載入」。
PWA／一般瀏覽器都適用，毋須重新安裝。
