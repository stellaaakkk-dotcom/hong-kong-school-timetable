香港教師教學日誌 v1.7.0

本版按 4 項優先更新：

1. 月曆日期快捷新增
- 撳日期圓圈會出現：
  📝 一般記事
  ＋ 活動紀錄
  ⏳ 待處理事項
- 一般記事仍沿用原本月曆 textarea，不會變 tag、不統計。

2. 待處理事項：重複 + 提前提醒
- 重複：不重複／每週／隔週／每月
- 提醒：到期日／1日前／3日前／7日前
- 今日工作台會顯示提前提醒、今日到期、逾期。
- 重複待辦按「完成」時：
  本次會保留完成紀錄；
  原待辦自動跳至下一個 deadline。

3. 月曆 tag 顯示開關
- 「更多」→ 🏷 月曆標籤
- 可獨立顯示／隱藏：
  活動紀錄 tag
  待處理事項 tag
- 只改顯示，不刪資料。

4. 月曆 tag 直接操作
- 撳「活動紀錄」tag → 直接修改日期／類別／名稱／備註。
- 撳「待辦」tag → 直接修改事項／deadline／優先級／重複／提醒／備註。
- 待辦亦有快捷：
  ＋1日／＋3日／下星期／完成今次。
